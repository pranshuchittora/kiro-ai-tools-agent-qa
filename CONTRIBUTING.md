# Contributing to Awesome AI Tools

Thanks for your interest in contributing! Here's how:

## How to Add a Tool

1. Fork this repository
2. Edit `README.md`
3. Add your tool in the correct category
4. Submit a Pull Request

## Format

```markdown
| [Tool Name](https://link.com) | Short description | Pricing |
```

## Rules

- ✅ Tool must be AI-powered
- ✅ Include working link
- ✅ Short description (under 50 characters)
- ✅ Accurate pricing info
- ❌ No affiliate links
- ❌ No self-promotion without disclosure
- ❌ No duplicate entries

## Categories

If your tool doesn't fit existing categories, suggest a new one in your PR description.

## Reporting Issues

- Broken links
- Outdated pricing
- Tools that no longer exist
- Miscategorized tools

Open an [Issue](../../issues) with details.

## Thank You! 🙏

Every contribution helps the community discover better AI tools.
